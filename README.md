# Mine-Wattehh

A simple Minecraft-inspired voxel engine built in C++ and OpenGL.

## Features
- water propagation simulation.
- Procedurally generated voxel terrain.
- Chunk-based world generation and rendering.
- Block placement/destruction.

## Deprecated
Development has been discontinued due to architectural limitations discovered during development. The repository is kept as an archive of one of my early graphics programming projects.
